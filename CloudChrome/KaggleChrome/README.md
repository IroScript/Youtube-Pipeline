# Kaggle Chrome & Cookie Session Automation Guide

ইরাক ভাইয়া, `CloudChrome\KaggleChrome` ফোল্ডারে ক্যাগলের সমস্ত ক্রোম অটোমেশন ও সেশন কুকি পরিচালনার জন্য প্রয়োজনীয় ফাইলসমূহ তৈরি করা হয়েছে।

## ফাইল তালিকা:

1. **`export_local_cookies.py`**: 
   - আপনার লোকাল পিসির ব্রাউজার থেকে নেওয়া কুকিজ ক্যাগলে ব্যবহারযোগ্য JSON ফরম্যাটে ফরম্যাট ও সংরক্ষণ করার স্ক্রিপ্ট।

2. **`kaggle_chrome_setup.py`**:
   - ক্যাগল এনভায়রনমেন্টে হেডলেস ক্রোম চালনা করা এবং ডেটাসেট ফাইল থেকে সেশন কুকিজ অটোমেটিক লোড করার মোডিউল।

3. **`kaggle_script_template.py`**:
   - ক্যাগল নোটবুকে ব্যবহারের জন্য একটি সম্পূর্ণ কপি-পেস্টযোগ্য সিঙ্গেল ফাইলের পাইথন টেমপ্লেট (যেটি Requests সেশন এবং Selenium Headless Chrome উভয়ই সমর্থন করে)।

---

## ব্যবহারের ধাপসমূহ:

### ধাপ ১: লোকাল কুকি ফাইল তৈরি
১. ব্রাউজারে সাইটে লগইন করা অবস্থায় **Cookie-Editor** বা অনুরূপ এক্সটেনশন ব্যবহার করে কুকিজ কপি করুন।
২. ফাইলটি `cookies.json` নামে সংরক্ষণ করুন।

### ধাপ ২: ক্যাগলে আপলোড
১. [Kaggle Datasets](https://www.kaggle.com/datasets)-এ যান।
২. একটি নতুন প্রাইভেট ডেটাসেট তৈরি করে `cookies.json` ফাইলটি আপলোড করুন।
৩. ডেটাসেটের পারমিশন অবশ্যই **Private** রাখবেন।

### ধাপ ৩: ক্যাগল নোটবুকে স্ক্রিপ্ট চালনা
১. ক্যাগল নোটবুকের справа `Input` বিভাগে তৈরি করা প্রাইভেট ডেটাসেটটি অ্যাড করুন।
২. `kaggle_script_template.py` কোডটি নোটবুক সেলে ব্যবহার করুন এবং `COOKIE_FILE_PATH`-এ আপনার প্রাইভেট ডেটাসেটের ফাইল পাথটি বসিয়ে রান করুন।
