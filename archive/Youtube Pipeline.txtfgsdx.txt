  ### ৪. ইউটিউব এপিআই ক্রেডেনশিয়াল সেটআপ গাইড

  ইউটিউব এপিআই লাইভ করার জন্য .env.example ফাইলটির ভিত্তিতে .env ফাইল তৈরি করে নিচের ভ্যালুগুলো প্রদান করতে হবে:

    # YouTube Data API v3 Credentials (OAuth 2.0)
    YOUTUBE_CLIENT_ID=your-google-oauth-client-id.apps.googleusercontent.com
    YOUTUBE_CLIENT_SECRET=your-google-oauth-client-secret
    YOUTUBE_REFRESH_TOKEN=your-long-lived-oauth2-refresh-token

    # Optional: Default Channel ID
    YOUTUBE_CHANNEL_ID=your-channel-id

  • ক্রেডেনশিয়াল পাওয়ার উপায়: Google Cloud Console -> APIs & Services -> Credentials -> Create OAuth 2.0 Client ID (Desktop
  Application)।
  • টোকেন জেনারেট হওয়ার পর রিফ্রেশ টোকেন এখানে বসালে youtube_adapter.py স্বয়ংক্রিয়ভাবে ভিডিও আপলোড ও রেজুমেবল আপলোড শুরু করতে পারবে।
