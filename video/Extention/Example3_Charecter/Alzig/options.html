How to Use

Follow these steps to automate your video creation process:

  1. Navigate to Google Flow: Open a project page in Google Flow. The extension icon will become active.
  2. Open the Extension: Click on the "Alzig Flow Pro" icon in your browser's toolbar to open the popup. open the popup.
  3. Configure Settings:
    • Batch Size: Choose how many prompts to process in one go.
    • Auto-pause: Set a number of videos after which the process will pause automatically.
    • Auto-download: Enable this to save videos as soon as they are generated.
    • Create unique folders: Enable to save videos in folders named after your input files.
  4. Upload Prompt Files: You have two options for uploading:
    • Multiple Files (Each file = 1 prompt): Use this if each of your `.txt`, `.json`, or `.docx` files contains a single prompt.
    • Single/Multiple Files (Each line = 1 prompt): Use this if you have one or more `.txt` files where each line represents a different prompt. The extension will process these files one by one.
  5. Start Processing: Click the "Start Batch Processing" button. The extension will begin creating videos.
  6. Monitor Progress: You can see real-time progress, view logs, and use the pause, resume, or stop controls as needed.

  • Batch processing from single or multiple files.
  • Sequential processing of files to ensure completion.
  • Support for TXT, DOCX, and JSON file formats.
  • Customizable batch size and auto-pause settings.
  • Real-time progress monitoring and detailed logging.
  • Controls to pause, resume, and stop the automation process.
