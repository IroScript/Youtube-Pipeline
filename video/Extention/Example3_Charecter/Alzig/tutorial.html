⚡ Quick Start (30 seconds)

  1. Open Google Flow → labs.google/fx/tools/flow
  2. Click the extension icon in your toolbar
  3. Add prompts (type, paste, or import file)
  4. Click "Add to Queue" then "Start Queue"
  5. Watch videos generate automatically!
🎉 That's it! Videos will download automatically when ready.

🚀 1. Getting Started

Installation

  1. Download the extension files
  2. Open Chrome and go to chrome://extensions
  3. Enable "Developer mode" (top right toggle)
  4. Click "Load unpacked" and select the extension folder
  5. Pin the extension to your toolbar for easy access

First Steps

  1. Navigate to Google Flow
  2. Click the Alzig Flow Pro icon in your toolbar
  3. The side panel will open with the extension interface
💡 Tip: The extension only works on the Google Flow project page. Make sure you're on labs.google/fx/tools/flow

🎮 2. Control Tab - Main Operations

The Control tab is your main workspace for adding prompts and managing automation.

Adding Prompts

You have three ways to add prompts:

✍️ Write Mode

Type prompts directly in the textarea. Separate each prompt with a blank line.

📁 File Upload

Upload .txt, .json, or .docx files. Drag & drop or click to browse.

✨ AI Generator

Use Gemini AI to generate scene-consistent video prompts automatically.

📋 Clipboard

Click "Paste from Clipboard" to quickly add copied text.

Processing Controls

  • ▶️ Start Queue: Begin processing all prompts in the queue
  • ⏸️ Pause: Temporarily pause processing (resume with same button)
  • ⏹️ Stop: Completely stop and reset the processing

Status Display

During processing, you'll see:

  • Current prompt being processed
  • Progress bar showing completion percentage
  • Count of completed, failed, and remaining prompts

✨ 3. AI Prompt Generator (Gemini)

The AI Prompt Generator uses Google's Gemini API to create scene-consistent prompts optimized for Veo 3.1.

Getting Your API Key

  1. Click the "Get Free API Key from Google AI Studio" button
  2. Sign in to Google AI Studio
  3. Create a new API key (it's free!)
  4. Copy the key and paste it in the extension
  5. Click "Save" to store it securely

Configuration Options

  • Number of Prompts: Generate 1-100 prompts at once
  • Theme/Subject: Describe your video topic (optional)
  • Style Presets: Cinematic, Documentary, Abstract, Product, Nature, Sci-Fi, Fantasy, Minimal
  • Prompt Length: Short (15-25 words), Medium (30-50), Long (50-80)

Advanced Options

  • Creativity Level: Adjust from Focused to Creative
  • Include in Prompts: Style, Composition, Colors, Lighting, Mood
  • Keywords Filter: Must-include and exclude keywords
🔗 Consistency Block: Generated prompts include a Consistency Block showing the exact character/subject description, style, and audio that repeats in every scene. This prevents identity drift in Veo 3.1!

Export Options

  • 📄 TXT: All prompts in a single text file
  • 📋 JSON: Structured JSON with metadata
  • 📁 Individual Files: Each prompt as prompt001.txt, prompt002.txt (JSON format inside)
  • ➕ Add to Queue: Import directly to the processing queue

📋 4. Queue Management

The queue holds all prompts waiting to be processed.

Queue Actions

  • Add to Queue: Adds prompts from textarea or files
  • Clear Queue: Removes all items from queue
  • Manage: Opens detailed queue modal

Manage Queue Modal

  • Search: Filter prompts by text
  • Select All: Toggle selection of all items
  • Remove Selected: Delete selected prompts from queue
⚠️ Important: Clearing the queue during processing will stop all pending prompts. Already-completed videos will remain.

⚙️ 5. Settings Configuration

Generation Settings

  • Model Version: Select Veo 3.1 Fast, Standard, or other models
  • Aspect Ratio: 16:9 (Landscape) or 9:16 (Portrait)
  • Outputs Per Prompt: How many video variations per prompt

Processing Settings

  • Batch Size: Number of concurrent prompts (1-5)
  • Wait Time Range: Random delay between actions
  • Start From N: Skip first N prompts in queue

Download Settings

  • Auto Download: Automatically download completed videos
  • Job Folder Naming: Create unique folders for each session
  • Custom Download Path: Specify where to save files
💡 Developer Mode: Enable for detailed console logging and debugging information.

📥 6. Downloads & Exports

Video Downloads

  • Download All Videos: Download all completed videos at once
  • Download All Images: Download thumbnail images
  • Auto Download: Videos download automatically when ready

Export Options

  • Export Report: Generate a detailed processing report
  • Generate Merge Script: Creates FFmpeg batch script to merge all videos

Video Merge Script

The merge script generator creates a Windows batch file that:

  1. Lists all .mp4 files in the folder
  2. Concatenates them using FFmpeg (must be installed)
  3. Outputs a single merged video
⚠️ Requirement: FFmpeg must be installed and in your system PATH for the merge script to work.

☁️ 8. Cloud Sync

Your data is automatically synchronized to the cloud, so you never lose your settings!

What Gets Synced

  • Flow Settings: Model, aspect ratio, outputs per prompt
  • Prompt History: All your previous prompts
  • Statistics: Total videos generated, processing time
  • Custom Presets: Your saved AI generator configurations
  • Theme Preferences: Dark/light mode settings

How It Works

  1. Activate your license key
  2. Extension automatically syncs in the background
  3. If you reinstall → Enter license key → Everything restored!
💡 Multi-Device: Use on up to 3 devices with the same license. Your settings sync automatically across all your devices!

📊 7. History & Logs

Processing Logs

The History tab shows a real-time log of all actions:

  • ✅ Green: Successful operations
  • ⚠️ Yellow: Warnings
  • ❌ Red: Errors and failures

Failed Tasks

  • Copy Failed: Copy failed prompts to clipboard
  • Retry Failed: Add failed prompts back to queue
  • Clear Logs: Clear the log history

💡 8. Pro Tips & Best Practices

For Best Results

  1. Use Google's 5-Part Formula:
    [Cinematography] + [Subject] + [Action] + [Context] + [Style]
  2. Keep Character Descriptions Identical: Use the same exact wording in every prompt for consistent characters
  3. Include Audio Cues: Use SFX: and Ambient noise: for Veo 3.1's audio generation
  4. Batch Size of 3-5: Optimal for most connections
  5. 4-8 Second Clips: Ideal length for consistent generation

Troubleshooting

  • Extension not working? Make sure you're on a Google Flow project page
  • Videos not downloading? Check your browser's download permissions
  • AI Generator errors? Verify your Gemini API key is valid
  • Processing stuck? Try refreshing the page and restarting

Keyboard Shortcuts

When focused on Google Flow:

  • Click extension icon to open/close side panel

❓ 11. Frequently Asked Questions

Q: Is Google Flow free to use?

Yes! Google Flow (VEO AI) is free to use. Our extension just automates the process of submitting prompts and downloading videos.

Q: Do I need a license to use the extension?

The free plan lets you generate a limited number of videos per day. For more capacity, you can upgrade to Standard or Premium plans.

Q: Can I use the extension on multiple computers?

Yes! Your license works on up to 3 devices. Your settings sync automatically between devices.

Q: Why isn't the extension connecting to Google Flow?

Make sure you're on the correct page: labs.google/fx/tools/flow. The extension only works on Google Flow project pages.

Q: How do I get a Gemini API key for AI prompts?

Click the "Get Free API Key" button in the AI Prompt Generator. It will take you to Google AI Studio where you can create a free API key.

Q: Videos are not downloading automatically?

Check that: 1) Auto-download is enabled in Settings, 2) Your browser allows downloads from Google, 3) You have a download folder selected.
